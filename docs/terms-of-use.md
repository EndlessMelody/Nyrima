## 1. Service Description

Nyrima is a Chrome extension that helps a user browse and play accessible
Google Drive video libraries in a dedicated player. Current features include

optional Drive-native sharing metadata, comments, and imports.

Nyrima is not a media hosting service, CDN, rights-clearing service, or promise
that every Drive media file and codec combination will play in Chrome.

- A share entry does not automatically grant access to the underlying target

Making future share metadata private or unsharing an entry may not remove local
